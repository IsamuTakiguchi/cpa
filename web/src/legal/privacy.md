# プライバシーポリシー

最終更新日: {{updated}}

{{operator}}（以下「運営者」）は、学習アプリ「{{appName}}」（iOS アプリおよび Web 版。以下「本アプリ」）における利用者の情報の取扱いを、次のとおり定めます。

## 1. 端末内にだけ保存する情報（iOS アプリ）

- 解答履歴、暗記カードの復習状態、メモ、まとめノート、学習設定、通知の設定は、利用者の端末内にだけ保存します。運営者のサーバーには送信しません。
- アプリを削除すると、これらのデータも削除されます。
- 「JSON を書き出す」で作成したバックアップファイルは、利用者が選んだ保存先（ファイル App、iCloud Drive など）に保存されます。

## 2. アプリ内課金に関する情報

- 購入の手続きは Apple が行います。運営者がクレジットカード番号などの支払い情報を受け取ることはありません。
- 購入状況の確認と「購入を復元」のために、購入管理サービス RevenueCat（RevenueCat, Inc.／米国）を利用します。RevenueCat には次の情報が送信されます。
  - アプリが自動で作成するランダムな識別子（匿名 ID）
  - 購入履歴（購入した商品、購入日時、ストア、有効期限など）
  - 端末の種類、OS のバージョン、アプリのバージョン、IP アドレスなどの技術情報
- これらは、購入状況の確認・復元、不正利用の防止、運営者による売上の集計にのみ使います。氏名・メールアドレスなど、利用者個人を特定する情報とは結び付けません。
- RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy/

## 3. 通知

学習リマインダーと手続き期限の通知は、端末内で予約するローカル通知です。通知のために情報を外部へ送信することはありません。

## 4. 広告・トラッキング・アクセス解析

本アプリは広告を表示しません。利用者を他社のアプリや Web サイトをまたいで追跡（トラッキング）することはなく、アクセス解析ツールも使用していません。

## 5. 外部サイトへのリンク

公式情報の確認のため、金融庁・公認会計士・監査審査会などの外部サイトへのリンクがあります。リンク先での情報の取扱いは、各サイトの方針に従います。

## 6. Web 版でログインした場合

iOS アプリにはログイン機能はありません。Web 版でアカウントを作成してログインした場合に限り、次の情報を扱います。

- メールアドレス（Google アカウントでログインした場合は、そのメールアドレス）と学習データを、端末間の同期とバックアップのために運営者のサーバーに保存します。
- AI 採点・AI まとめを利用した場合は、答案と問題の内容を、採点・要約のために Anthropic, PBC（米国）の API に送信します。送信した内容は Anthropic のポリシーに従って取り扱われます。

## 7. 第三者への提供

法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません（上記の委託先・サービスへの送信を除きます）。

## 8. 開示・訂正・削除のご請求

iOS アプリのデータは端末内にあるため、アプリの設定画面から削除できます（「この端末のデータをすべて削除」またはアプリの削除）。その他のご請求・お問い合わせは、下記までご連絡ください。

## 9. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更できます。変更後の内容は、本アプリ内に掲示した時点から効力を生じます。
