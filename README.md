# CPA 論文式 学習アプリ

2027年公認会計士試験（論文式）に向けた **会計学（財務会計論・管理会計論）／監査論／租税法** の学習アプリ。
PC とスマホのブラウザで動き（PWA としてホーム画面に追加可）、インプットとアウトプットを 1 つで回します。

## できること

- **インプット**: 論点ごとの要点ノート（定義→趣旨→論点→結論）、直前確認用の結論サマリー
- **アウトプット**（短時間〜本試験形式まで、問題数・制限時間・科目を自由に）
  - 暗記カード（間隔反復 SRS）／正誤問題／一問一答（キーワード自動判定）
  - 小論述（模範解答＋採点ポイントで自己採点、**Claude API による AI 採点・講評**）
  - 計算問題（数値入力・自動採点・解法表示）
  - 大問論述（本試験 1 問相当。枝問ごとに採点）
  - **本試験形式**: 科目ごとに本試験と同じ時間・大問数で通し解答→一括提出→採点
  - プリセット: スキマ5分／通勤15分／1論点集中30分／弱点補強
- **復習**: 期限到来カード、得点の低かった問題の再挑戦
- **まとめノート**: 範囲と素材（要点・カード・弱点・自分の答案・メモ）を選んで 1 枚に生成。印刷／PDF／Markdown コピー。AI による「直前確認ポイント」の付加
- **同期とバックアップ**: ログインで PC⇔スマホ同期（Railway 上の Postgres）。端末内にも常に完全コピーを保持し、オフラインでも学習可。JSON 書き出し／読み込み、サーバー内日次スナップショットからの復元

セットアップ手順は [SETUP.md](./SETUP.md) を参照してください。

## 構成

```
shared/   教材コンテンツと共有型（TypeScript）。論点 1 つ = 1 ファイル
web/      フロント（Vite + React + Tailwind + Dexie/IndexedDB + PWA）
server/   API（Hono + Drizzle ORM + Postgres）。web/dist も配信
```

### 教材の追加・修正

`shared/src/content/<科目>/topics/` に論点ファイルを追加し、同じ階層の `index.ts` の配列に加えます。
書き方は `shared/src/content/financial/topics/fa01-conceptual-framework.ts`（テンプレート）と `shared/src/content/types.ts` を参照。
`npm test` で ID の重複・配点合計などの整合性を自動チェックします。

> 教材は AI（Claude）が作成した学習補助資料です。2027年試験の適用基準・法令（租税法は試験年 4 月 1 日現在の法令）に照らして、必ず原典・基準書で確認してください。

## 開発

```bash
npm install
npm run dev          # web http://localhost:5173（/api は :3000 へプロキシ）
npm run typecheck && npm run lint && npm test
npm run build && npm start
```
